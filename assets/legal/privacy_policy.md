# ツクレピ プライバシーポリシー

制定日：2026年10月5日
最終更新日：2026年10月5日

【運営者名】（以下「運営者」といいます。）は、アプリケーション「ツクレピ」およびこれに関連するサービス（以下、総称して「本サービス」といいます。）における利用者情報を、以下のとおり取り扱います。

## 1. 取得する情報

運営者は、本サービスの提供に必要な範囲で、次の情報を取得することがあります。

### 1.1 アカウント情報

- AppleまたはGoogle等の認証事業者が発行する利用者識別子
- 利用者が提供を許可した場合のメールアドレス、表示名等
- ログイン日時、認証状態およびアカウントに関する情報

AppleまたはGoogleのパスワードを運営者が取得・保存することはありません。

### 1.2 利用者が入力または共有する情報

- Instagram、TikTokその他のSNS投稿URL
- 投稿文、公開プロフィール名、公開ユーザー名、サムネイルその他、対象投稿から取得可能な公開情報
- 利用者が選択または共有した画像、動画、音声およびスクリーンショット
- 取り込み時のメモ、AIへの質問、編集内容、アレルギー・苦手な食材の設定
- 解析により生成されたレシピ、材料、分量、調理手順その他の結果
- お気に入り、作った記録、コレクション、買い物リスト等の保存情報

### 1.3 課金および利用枠に関する情報

- 購入したプランまたは追加回数
- 購入状態、更新・失効日時、取引を識別する情報
- 無料枠、利用済み回数、残り回数等

クレジットカード番号等の決済情報はAppleまたはGoogleが取り扱い、運営者は取得しません。

### 1.4 端末・利用状況・障害情報

- 端末種別、OS、アプリのバージョン、言語、タイムゾーン等
- アプリ内で発行する端末識別子および通知トークン
- 機能の利用状況、解析状態、重複判定情報、不正利用防止に必要な情報
- エラー、クラッシュ、通信記録、処理時間その他の診断情報

広告目的の追跡を行う場合は、法令およびプラットフォームの規則に従い、必要な同意を取得します。現時点で本サービスは、第三者広告のための行動追跡を目的としてこれらの情報を利用しません。

## 2. 情報の利用目的

取得した情報を次の目的で利用します。

1. アカウントの作成、本人確認およびログイン状態の維持
2. SNS投稿、画像、動画、音声、投稿文およびメモの取得・解析
3. AIによるレシピ生成、料理に関する質問回答および画像確認機能の提供
4. レシピ、利用者設定および利用履歴の保存・同期・復元
5. 無料枠、解析回数、定期購入および追加購入の管理
6. 重複解析、連打、同時送信、不正取得および規約違反の防止
7. 解析完了その他、利用者が有効にした通知の送信
8. 問い合わせ対応、障害調査および重要なお知らせの配信
9. 個人を直接識別しない形での利用状況の集計、品質改善および機能開発
10. 法令、本規約および権利者からの正当な申出への対応

## 3. 外部サービスへの送信および委託

本サービスでは、機能提供のため次の外部サービスを利用することがあります。送信される情報は、各機能に必要な範囲に限定します。

| 外部サービス | 主な目的 | 送信される可能性がある情報 |
| --- | --- | --- |
| Supabase | 認証、データベース、ストレージ、サーバー処理 | アカウント識別子、保存データ、利用回数、解析状態、設定情報 |
| Apple / Google | ログイン、アプリ内課金 | 認証情報、購入・契約状態、取引識別情報 |
| RevenueCat | 課金状態と利用権の管理 | アプリ利用者識別子、商品・購入・契約情報 |
| Firebase Cloud Messaging | プッシュ通知 | 通知トークン、端末・通知配信に必要な情報 |
| Google Cloud | 動画・画像・音声等の処理、サーバー実行 | 対象URL、選択されたメディア、解析処理に必要な情報 |
| OpenAI等のAIサービス | レシピ解析、文章・画像の理解、質問回答 | 投稿文、メモ、選択された画像、動画から抽出した情報、質問内容 |
| Apify等の投稿情報取得サービス | 公開SNS投稿情報の取得 | 対象SNSのURL、取得に必要な公開投稿情報 |

外部サービスの構成を変更した場合は、実際のデータ取扱いに合わせて本ポリシーを更新します。各事業者は、日本国外のサーバーで情報を処理する場合があります。運営者は、契約、各事業者の公開情報その他合理的な方法により、委託先の安全管理を確認します。

## 4. 第三者提供

運営者は、次の場合を除き、利用者を識別できる個人情報を第三者へ提供しません。

1. 利用者本人の同意がある場合
2. 本サービスの提供に必要な範囲で、前項の事業者等へ取扱いを委託する場合
3. 法令に基づく場合
4. 人の生命、身体または財産の保護に必要で、本人の同意を得ることが困難な場合
5. 事業承継に伴い情報が移転される場合

## 5. 情報の保存期間

1. アカウント情報および利用者が保存したレシピ等は、原則としてアカウントが存続する間保存します。
2. アカウント削除後は、法令上の保存義務、不正利用防止、取引記録の保持または紛争対応に必要な情報を除き、合理的な期間内に削除または匿名化します。無料枠の反復取得を防ぐため、AppleまたはGoogle等の認証識別子を秘密鍵付きハッシュで不可逆化した値だけを、削除後3年間保持します。この値からメールアドレス、氏名その他の認証情報を復元することはできません。
3. 解析のため一時的に生成した動画、画像、音声、フレームその他の中間ファイルは、処理および障害対応に必要な期間を超えて保持しないよう努めます。
4. バックアップに含まれる情報は、通常の更新サイクルに従って順次削除されます。
5. 購入・取引、不正利用防止およびシステムログは、法令遵守と安全管理に必要な期間保存することがあります。

## 6. 安全管理措置

運営者は、アクセス制御、通信の暗号化、権限管理、認証、ログ監視、バックアップその他、利用者情報の漏えい、滅失、毀損または不正アクセスを防止するための合理的な措置を講じます。ただし、インターネット上の通信・保存について絶対的な安全性を保証するものではありません。

## 7. 利用者による確認・訂正・削除

1. 利用者は、アプリ内の機能を通じて、保存したレシピ、メモ、設定等を確認、訂正または削除できます。
2. 利用者は、アプリ内のアカウント設定から、アカウントおよび関連データの削除を申し込むことができます。
3. Appleでログインしている利用者のアカウント削除時には、必要に応じてAppleの認証トークンを失効させます。
4. 定期購入は、アカウント削除とは別に、App StoreまたはGoogle Playの設定から解約する必要があります。
5. 保有個人データの開示、訂正、利用停止、消去その他法令上の請求を希望する場合は、本ポリシー末尾の窓口へご連絡ください。本人確認後、法令に従って対応します。

## 8. 端末の権限

本サービスは、利用者が選択した機能に応じて、カメラ、写真、通知等の端末権限を求めることがあります。各権限は、撮影した料理画像の確認、画像の選択、解析完了通知等、表示された目的のために使用します。利用者は端末設定から権限を変更できますが、一部機能が利用できなくなる場合があります。

## 9. 子どもの利用

未成年者は、必要に応じて親権者その他の法定代理人の同意を得て本サービスを利用してください。運営者が、法定代理人の同意なく取得された子どもの情報を把握した場合、適切な確認のうえ削除等の対応を行います。

## 10. 外部SNSおよびリンク

本サービスからInstagram、TikTokその他の外部サービスへ移動した場合、その外部サービスにおける情報の取扱いには、当該サービスのプライバシーポリシーが適用されます。本サービスは、利用者のSNSアカウントのパスワードを取得しません。

## 11. 本ポリシーの変更

運営者は、法令、サービス内容または利用する外部サービスの変更等に応じて、本ポリシーを変更することがあります。重要な変更を行う場合は、効力発生日および変更内容をアプリ内その他適切な方法で通知します。

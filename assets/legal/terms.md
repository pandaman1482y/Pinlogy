# ツクレピ 利用規約

制定日：2026年10月5日
最終更新日：2026年10月5日

本利用規約（以下「本規約」といいます。）は、【運営者名】（以下「運営者」といいます。）が提供するアプリケーション「ツクレピ」およびこれに関連するサービス（以下、総称して「本サービス」といいます。）の利用条件を定めるものです。利用者は、本規約に同意したうえで本サービスを利用するものとします。

## 第1条（本サービスの内容）

1. 本サービスは、利用者が指定または共有したSNS投稿のURL、投稿文、画像、動画、音声、メモその他の情報を解析し、料理の材料、分量、調理手順等を整理して保存・閲覧できる機能を提供します。
2. 本サービスには、AIによる解析、料理に関する質問回答、画像を利用した補助的な確認、レシピの保存・同期、通知その他の機能が含まれる場合があります。
3. 本サービスがSNS上の投稿、画像または動画を取得・解析できることは、その投稿の利用許諾、正確性、合法性または継続的な取得可能性を保証するものではありません。

## 第2条（アカウント）

1. 本サービスの利用には、AppleまたはGoogle等、運営者が指定する方法によるログインが必要となる場合があります。
2. 利用者は、自己の責任においてアカウントおよび認証情報を管理するものとし、第三者に利用させてはなりません。
3. 利用者のアカウントを用いて行われた操作は、運営者に故意または重大な過失がある場合を除き、当該利用者による操作として取り扱います。
4. 利用者は、アプリ内の所定の手続によりアカウント削除を申し込むことができます。削除に伴い、法令上保存が必要な情報を除き、アカウントに関連する保存データは削除され、復元できなくなる場合があります。
5. アカウントを削除しても、App StoreまたはGoogle Play上の自動更新契約が自動的に解約されるとは限りません。利用者は各ストアの設定から定期購入を確認・解約する必要があります。

## 第3条（無料利用枠および有料サービス）

1. 運営者は、所定回数の無料解析枠を提供する場合があります。無料解析枠は原則としてアカウント単位で管理します。
2. 無料解析枠の回数、付与条件、有効期間その他の条件は、アプリ内に表示する内容によります。
3. 本サービスでは、自動更新される月額・年額プランまたは解析回数の追加購入を提供する場合があります。価格、利用可能回数、更新期間およびその他の条件は、購入画面に表示します。
4. 定期購入は、利用者が各ストアで解約しない限り、表示された期間ごとに自動更新されます。解約方法および返金の取扱いは、原則としてAppleまたはGoogle等の決済事業者の規約に従います。
5. 解析回数は、原則として解析に成功しレシピが作成された場合に消費します。ただし、購入画面またはアプリ内で別途条件を明示した場合は、その条件が適用されます。
6. 通信障害、対象投稿の削除・非公開化、外部サービスの制限その他の事情により解析できない場合があります。
7. 利用者による不正取得、複数アカウントの濫用、技術的手段による無料枠の反復取得その他、運営者が不適切と判断する利用があった場合、無料枠の取消し、利用制限またはアカウント停止を行うことがあります。

## 第4条（AI解析結果および調理上の注意）

1. AI解析結果には、材料、分量、調理手順、加熱時間、保存期間、アレルゲンその他の情報の誤り、抜け、推測が含まれる場合があります。
2. 利用者は、調理前に元投稿、食品の原材料表示、商品の注意事項および公的機関等の信頼できる情報を確認してください。
3. アレルギーまたは苦手な食材の検出・注意表示は補助機能であり、完全な検出を保証しません。重篤なアレルギーがある場合は、本サービスの表示だけで判断しないでください。
4. 加熱時間、加熱温度および保存期間は、食材の状態、分量、調理器具、室温、保存環境等によって変わります。利用者は食材の中心部まで十分に加熱されていること等を自身で確認してください。
5. 本サービスは、医療、栄養または食品衛生に関する専門的助言を提供するものではありません。

## 第5条（SNS投稿および知的財産権）

1. SNS投稿、画像、動画、音声、文章、レシピその他のコンテンツに関する著作権、商標権、肖像権その他の権利は、投稿者または正当な権利者に帰属します。
2. 利用者は、自ら利用する権限を有するコンテンツ、または私的利用その他法令上認められる範囲のコンテンツのみを本サービスに入力・共有するものとします。
3. 本サービスは、SNS投稿の権利を利用者へ移転するものではありません。利用者は、解析結果や元投稿の画像等を第三者へ再配布、公開または商用利用する場合、自ら必要な許諾を取得するものとします。
4. 運営者は、権利者から正当な申出を受けた場合、対象URL、投稿または投稿者からの取り込みを制限し、関連データを削除することがあります。
5. 利用者は、元投稿へのリンクおよび出典情報を削除・改変することで権利者または投稿者について誤解を生じさせてはなりません。

## 第6条（利用者データ）

1. 利用者が入力・保存したURL、メモ、画像、解析結果その他のデータに関する権利は、当該利用者または正当な権利者に留保されます。
2. 利用者は、本サービスの提供、解析、同期、障害対応、不正利用防止および品質改善に必要な範囲で、運営者が利用者データを処理することを許諾します。
3. 運営者は、利用者データの取扱いについて、別途定めるプライバシーポリシーに従います。
4. 利用者は、重要な情報について自らバックアップを確保するものとします。

## 第7条（禁止事項）

利用者は、本サービスの利用にあたり、次の行為をしてはなりません。

1. 法令、公序良俗、本規約またはSNS等の第三者サービスの適用規約に違反する行為
2. 他人の権利または利益を侵害する行為
3. 権限のないアカウント、非公開情報またはアクセス制限された情報を不正に取得・解析する行為
4. 本サービスまたは外部サービスに過度な負荷を与える行為
5. 無料枠、解析回数、重複防止その他の制限を回避する行為
6. リバースエンジニアリング、不正アクセス、脆弱性の探索または本サービスの運営を妨害する行為
7. 虚偽情報の登録、他人へのなりすましまたはアカウントの不正利用
8. 本サービスを用いて第三者のコンテンツを無断で複製、配布、販売または公開する行為
9. その他、運営者が本サービスの適正な運営を妨げると合理的に判断する行為

1. 運営者は、保守、障害対応、外部サービスの仕様変更、法令対応その他必要な場合、本サービスの全部または一部を変更または停止することがあります。
2. 重要な変更または長時間の停止が見込まれる場合、運営者は可能な範囲でアプリ内その他適切な方法により通知します。
3. Instagram、TikTokその他の外部サービスの仕様、公開状態または利用条件により、投稿を取得・解析できなくなる場合があります。

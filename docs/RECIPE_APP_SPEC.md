# Recipe App 固定仕様

## 画面

| タブ | 役割 |
|---|---|
| レシピ | 4:5の長方形サムネイルを2列表示。処理中の仮カードも先頭に表示 |
| 検索 | キーワード、料理種別、主材料、難易度、SNS、お気に入りで絞り込み |
| AI | 保存済みレシピを根拠に献立や候補を提案 |
| マイページ | ログイン、同期、通知、アレルギー、フィードバック |

詳細画面と調理モードではボトムナビを表示しません。全画面を強制的に明るい白基調で統一します。

## 抽出と保存

- 1投稿から複数の料理を抽出できます。1料理なら自動保存、複数なら候補選択画面を表示します。
- 1料理の本体、タレ、出汁、漬け込み、トッピングは `parts` で分離します。
- 保存後も材料、分量、手順、パート、根拠を編集できます。
- 根拠には元画像、キャプション、OCR、動画時刻、信頼度を持てます。
- 根拠の優先順位は「ユーザー修正 > キャプション > 明瞭な画像 > 投稿者の固定コメント > 音声 > AI推定」です。
- 「適量」などの曖昧な分量は勝手に数値化せず、要確認として残します。

## バックグラウンド処理

OSの共有拡張が元URLと最小限のペイロードを保存し、Supabaseの耐久ジョブを即時に登録します。サーバーがSNS画像取得とAI抽出を行うため、アプリを開き続ける必要はありません。

状態は `queued -> processing -> completed | failed | cancelled` で永続化し、アプリ起動時に結果を回収します。通知OFFでもジョブは完了し、次回起動時に表示します。

## 安全

- 元動画は保存せず、元URL、トップ画像、抽出データを保存します。
- アレルギー設定はAI提案の回避に使いますが、完全性は保証しません。元投稿と商品表示の確認を常に促します。
